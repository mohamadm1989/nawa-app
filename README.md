## 📖 نبذة عن المشروع

**نوى** هو تطبيق Flutter مخصص لإعادة الإعمار المجتمعي في سوريا. يهدف التطبيق إلى بناء جسر الثقة بين المتبرعين والمشاريع التنموية من خلال نظام شفافية متقدم ومراجعة مجتمعية.

### 🎯 الرؤية
> "كل مساهمة، مهما كانت صغيرة، يمكن أن تكون نواة لتغيير إيجابي كبير"

### 🌟 الرسالة
ربط قلوب المتبرعين الكريمة بالمشاريع التي تحتاجها سوريا، مشروع واحد في كل مرة.

## ✨ المميزات

### 🔐 نظام الثقة الثلاثي
- **📋 التوثيق المسبق**: مراجعة دقيقة للمشاريع قبل النشر
- **👁️ الشفافية المستمرة**: تتبع تقدم المشاريع بالتفصيل
- **🗳️ المراجعة المجتمعية**: تقييمات وتعليقات من المجتمع

### 💳 نظام دفع آمن
- دعم متعدد لطرق الدفع (Visa, Mastercard, PayPal)
- معاملات مشفرة وآمنة
- إيصالات فورية مع شكر شخصي

### 📱 تجربة مستخدم متميزة
- تصميم عربي أصيل مع خط Cairo
- دعم كامل للاتجاه RTL
- ألوان مستوحاة من العلم السوري
- رسوم متحركة سلسة

### 🌍 ميزات إضافية
- خرائط تفاعلية لمواقع المشاريع
- نظام إشعارات شامل
- صفحة أثر المساهمة الشخصية
- دعم متعدد اللغات (العربية/الإنجليزية)

## 🚀 التثبيت

### المتطلبات
- Flutter SDK 3.24.0 أو أحدث
- Dart SDK 3.5.0 أو أحدث
- Android Studio / VS Code
- Git

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/mohamadm1989/nawa-app.git
cd nawa-app
```

2. **تثبيت التبعيات**
```bash
flutter pub get
```

3. **تشغيل التطبيق**
```bash
# للويب
flutter run -d chrome

# للأندرويد
flutter run -d android

# لـ iOS
flutter run -d ios
```

### إعداد Firebase (اختياري)
1. إنشاء مشروع Firebase جديد
2. إضافة ملفات التكوين:
   - `android/app/google-services.json`
   - `ios/Runner/GoogleService-Info.plist`
3. إلغاء تعطيل Firebase في `pubspec.yaml`

## 📱 الاستخدام

### للمتبرعين
1. **التسجيل**: إنشاء حساب جديد أو تسجيل الدخول
2. **استكشاف المشاريع**: تصفح المشاريع المتاحة
3. **التبرع**: اختيار مشروع والتبرع بأمان
4. **المتابعة**: تتبع تقدم مشاريعك المدعومة

### لمنشئي المشاريع
1. **إنشاء مشروع**: تقديم تفاصيل المشروع
2. **التوثيق**: رفع المستندات والوسائط
3. **المراجعة**: انتظار مراجعة المجتمع
4. **التنفيذ**: بدء العمل وتحديث التقدم
